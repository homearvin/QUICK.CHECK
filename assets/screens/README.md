# QuickCheck product screenshots

These are captures of QuickCheck 2.15.0 using the application's fictional demonstration class. All teacher and learner names and all scores shown are invented sample data. No real teacher records were opened or captured.

The SVG files are frozen vector captures of the actual rendered app DOM and its resolved styles. Text, controls, charts, and icons stay sharp at any display density. They contain no scripts, event handlers, forms that submit, or external resources. The sample paper photograph is embedded inside the review image. Only the demo-only exit banner and checklist were omitted by the isolated capture harness. `skills-detail.svg` and `record-detail.svg` crop the actual Skills and class scorebook screens.

Desktop captures use a 1440 × 900 viewport; the phone capture uses 390 × 844. The Skills and class-record details are 631 × 568 and 638 × 568. The earlier compressed WebP captures remain in the repository as legacy assets, but the website uses the SVG captures.

Captured on 12 November 2026 for the public QuickCheck website.
