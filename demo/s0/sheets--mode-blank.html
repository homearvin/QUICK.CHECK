Details
1

ForSheets made from a test match it exactly — the same items, the same answer choices, the same title — and can carry each learner’s name. A quick sheet is a plain one of any size; you set the test up later, before you check the papers. You can come back and change this.

Test Best Blank
2

ItemsType any number from 1 to 100, or tap one of the common sizes below.

3

ChoicesThese are the bubbles printed beside every item — A to D, True or False, or a matching set.

Matching type — one letter per option (A to F … A to N)

Every item gets a bubble for each option. Fewer options are easier for learners to shade accurately.

4

TitleFor example “Quiz 3 — Fractions”. Leave it empty and the sheet prints “ANSWER SHEET”.

5

Per pageMore sheets per page saves paper — you cut them apart after printing, and each piece is read just like a full sheet.

Small bubblesWith more than 25 items the bubbles print tiny — harder for learners to shade and harder for the camera to read. Use it only when paper is short.

6

PrintThe download is a PDF. Print it at full size on A4 — the four black corner squares must keep their size, because that is how the camera finds the sheet.

  • 100% sizePrint at actual size, not “Fit to page” — that shrinks the sheet, and the camera can no longer read it.
  • A4
  • Key before checkingThese blank sheets are not tied to a test yet. Before you photograph the papers, make a test in QuickCheck with the same number of items and the same answer choices, and type its answer key.
