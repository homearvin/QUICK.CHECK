Download and install QuickCheck

You only do this once. About three minutes.

  1. Press the green Download QuickCheck button — the one above, or the one at the top of the home page.
  2. Your browser saves a .zip file into your Downloads folder. It is about 87 MB, so give it a minute. If the browser asks whether to keep it, choose Keep.
  3. Open your Downloads folder, right-click the .zip file → Extract All…, and choose a normal folder such as Documents. Press Extract.
  4. Open the folder that appears and double-click QuickCheckPro.exe.
  5. Windows may show a blue box saying "Windows protected your PC". Click More info, then Run anyway.
  6. The first start takes up to a minute. Then the QuickCheck window opens — that is the app.
Extract the zip first — this matters. If you double-click the .exe while it is still inside the zip, Windows throws your work away when you close it. Extract to a real folder and everything is saved properly.
The blue warning is normal. Windows shows it for any new app that has not paid for a certificate. It is not a virus warning. QuickCheck runs entirely on your computer and does not need the internet to work.
Keep the QuickCheck window open while you work. Closing that window is how you close QuickCheck for the day. To open it again tomorrow, double-click QuickCheckPro.exe in the same folder — or right-click it once and choose Pin to Start so it is always one click away.

Your free trial, and entering your key

No key is needed for the first 7 days.

  1. The first time you open QuickCheck, a 7-day free trial starts by itself. A bar at the top shows how many days are left.
  2. When you buy, you receive a small file ending in .qckey by email. Save it into the same folder as QuickCheckPro.exe.
  3. Click Buy or enter a key on the trial bar. If the key file is next to the app, a one-click Activate "yourname.qckey" button is already there — press it. Otherwise click Click to choose your .qckey license file and pick it, then press Activate.
  4. That's it. You won't be asked again, and everything you made during the trial stays.
When the trial ends. QuickCheck becomes view-only: you can still open and download your results, but you can't check new papers until you enter a key. The free trial is once per computer.
One key, one computer. Your key locks to the computer you activate it on. If you change computers, ask for a new key. A key with a time limit starts counting from the day you activate it, not the day it was made.

A quick tour of the screen

Read this once and the rest of the guide is easy to follow.

Everything is in the left sidebar. On a phone it is the ☰ Menu button at the top.

  • HomeYour dashboard. It shows what to do next, how your classes are doing, the hardest questions, competency mastery, and the learners to follow up.
  • Check papersYour list of tests. This is where you make a test, photograph the papers and review them.
  • ResultsEvery test you have checked, with the reports you can print or download.
  • My classesYour class lists and class records.
  • Answer sheetsPrint the sheets your learners shade.
  • Phone accessThe QR code and PIN that connect your phone.
  • SettingsYour name, the folder for class records, report wording, backups, and the QuickCheck version.
The whole cycle, in order: class → test → answer key → print sheets → give the test → photograph the papers → review → save → results. Parts 4 to 13 below are exactly that order.
4

Add your class

QuickCheck needs your learners' names so it can match each paper to a learner.

Go to My classes → Add a class

Step 1 asks what kind of record you want. There are three:

DepEd format — build it here (recommended)

  1. No file needed. Type your school, grade and section and your subjects.
  2. Set the terms (quarters) and the categories with their percentages — Written Works, Performance Tasks, Quarterly Assessment.
  3. QuickCheck builds the Excel class record for you, and scores go straight into it.

Copy an existing e-class record

  1. Choose this if you already have a DepEd .xlsx e-class record.
  2. Upload it, and QuickCheck uses it as the template — your own columns, your own format.
  3. When you save scores later they go into that same file, in the right column, so you don't retype anything.

Simple scorebook

  1. Just a list of learners — good for quizzes.
  2. Scores stay inside QuickCheck and download as a plain Excel file.

Then Step 2 — Add students: type the names, or paste a whole list at once (one name per line) and press Add these names. Step 3 — Review & create shows you everything before it is saved.

Which should you pick? Use a DepEd record if your scores have to land in the file you submit. A simple scorebook is fine for quizzes — just download the scores if you need them elsewhere. You can have as many classes as you like.
5

Make a test

One test = one exam or quiz. Four numbered steps.

Go to Check papers → Create test

  1. Name the test. Name it the way you would say it out loud, e.g. "First Term Exam — Math 8".
  2. Which class takes this test? Pick it from your list. Its learners are the ones matched to the papers, and their scores are saved in that class record.
  3. What does the answer sheet look like? Type how many items, then choose the answer choices:
    • True/False, A–C, A–D, A–E — ordinary multiple choice.
    • Matching type — A–F up to A–N. Every question gets one bubble per option, so a 10-item matching set gives each row A to J.
    • Parts — for an exam that mixes types, add a part for each one (for example Part I, items 1–20, A–D; Part II, items 21–30, matching A–J).
  4. Where do the scores go? Pick the term and the column of your class record this test fills in — for example Written Works 1.
  5. Press Save and continue. The page then shows you what happens next.
A picture of the sheet is shown as you choose. The preview on the right updates while you pick the items and choices, so you can see exactly what your learners will get before you print anything.
6

Build a Table of Specifications (optional)

Do this if you want to know which competencies your learners did not master.

Right after you make a test, QuickCheck asks: build a TOS first, or skip straight to the answer key?

  1. Type each competency you taught, and how many days you spent on it.
  2. QuickCheck works out the rest the DepEd way — days ÷ total days × total items — and the item counts always add up exactly to your test.
  3. Each competency is given its own item numbers (for example, items 39–50).
  4. Press Save Table of Specifications. You go straight on to the answer key.
Why this is worth five minutes. Because each competency owns specific item numbers, after you check the papers QuickCheck can tell you which competencies the class failed and which learners need help in each one — with no extra typing. You can also print the TOS itself, which many schools ask for.
You can skip it. Skipping is completely fine — you still get scores and item analysis. You can add a TOS later from the test's TOS button.
7

Type the answer key — and set the points

The correct answers. Without this, nothing can be scored.

  1. Tap the correct answer for each item. Go down each column — the counter on the right shows how many are still empty.
  2. How many points is each item worth? Choose one of the two:
    • Every item is worth 1 point — what most tests use.
    • Some items are worth more — set a range and its points, for example items 1 to 5, 5 points each. Press Add another range for more. Items you don't list stay at 1 point.
  3. The card on the right shows the highest possible score as you type, so you can check it matches your paper.
  4. Press Save key & continue.
Points are used everywhere. Scores, your class record and every report use the points you set. A learner who gets a 5-point item right gains 5 marks, not 1.
Made a mistake? Open the test any time and press Edit answer key. Once papers have been uploaded or saved the key is locked so scores can't change under you — to correct it, remove those papers first, fix the key, and check them again.
8

Print the answer sheets

Learners must shade QuickCheck's own sheet — that is what the camera reads.

Go to Answer sheets

  1. What are you printing sheets for? Choose a test I already made (the usual one), or a quick quiz with no test yet if you only want blank sheets to keep on hand.
  2. Pick the test. The sheet is built from it — its items, answer choices and name. Use the search box if you have many tests.
  3. Named sheets or blank sheets?
    • One named sheet per learner — each learner's name is printed on their sheet. Faster to hand out, and when you check the papers the printed name tells you at a glance whose paper it is.
    • Blank sheets — learners write their own name.
  4. How many sheets on one A4 page? 1 is the recommended setting. 2 or 4 per page saves paper — you cut them apart after printing, and each piece scans like a full sheet. QuickCheck warns you if the test has too many items for 4 per page.
  5. Download, then print. You get a PDF. Print it with Actual size or 100% — not "Fit to page" — on A4, one side only. If you chose more than one per page, cut along the dashed lines.
Print at 100% — this is the one setting that matters. The black corner squares are how the camera finds and straightens the sheet. If the page is shrunk, or a corner is cut off, the paper cannot be read. Photocopies are fine as long as they are clear and not crooked.
Shorter sheets for new tests. A test you make now prints a compact sheet that ends just below the last question instead of running to the bottom of the page — less paper, and the same reading accuracy. Sheets you already printed for older tests keep working exactly as before.
9

Give the test

Nothing to do in the app — just three things to tell your class.

  1. Shade the bubble fully, with a dark pen or pencil.
  2. One bubble per question. Two marks on the same question can't be counted.
  3. Don't fold or tear the corners. The four black squares must stay on the paper.
Collect the papers face up in one pile. Photographing them goes much faster when they are all the same way round.
10

Connect your phone

Your phone becomes the scanner. You only set this up once per phone.

Go to Phone access on the computer

  1. Put the phone on the same Wi-Fi as this computer. A school Wi-Fi, a home Wi-Fi, or this computer's phone hotspot all work. It does not need internet.
  2. Point the phone's camera at the square (the QR code) on the screen, and tap the link that pops up. No app to install, no typing.
  3. Type the PIN shown on that same page. The phone asks for it once, so only you can send papers to this computer.
  4. If Windows asks about the firewall, click Allow for private networks.
Two things must be true. QuickCheck must be open on the computer, and both devices on the same Wi-Fi. No Wi-Fi at school? Turn on your phone's hotspot and connect the computer to it — that works anywhere and uses no mobile data. The address changes on each network, so just scan the QR code again.
Prefer to work on the computer? You can skip this part entirely and upload photos, a scanned PDF or a .zip from the computer instead — see the next part.
11

Check the papers

The part that used to take your evening.

Go to Check papers → open your test

Option A — from your phone (fastest)

  1. On the phone, open QuickCheck (the link you scanned in part 10) and open the same test.
  2. Press Take a photo and snap each paper — the whole sheet in frame, including the four black corners.
  3. The photos upload straight to the computer as you go.

Option B — from the computer

  1. Open the test and choose the files: photos, a scanned PDF (each page is one paper), or a .zip of photos.
  2. Press Read and review them.
A whole class takes a moment to read. That is normal — wait for the review page. Your progress is saved, so you can stop and come back later. The page also lists Already checked papers and tips for clean photos.
"One more step before you can check". If you see that message, the test isn't ready yet — usually the answer key is missing. Press the dark green button on that card and QuickCheck takes you to the step that is missing.
12

Review each paper, then save

You see and approve every paper before anything is recorded.

  1. For each paper you see the marked photo — green for correct, red for wrong — and the answers QuickCheck read. Show original photo switches back to the plain picture.
  2. Whose paper, and is it right? Check the learner's name and change it from the list if it isn't the right one.
  3. If a bubble was misread, change that answer. The score updates as you do.
  4. Press Confirm & next and move to the next paper.
  5. Missed a paper? Use Add another paper at the bottom — it joins the same batch.
  6. When every paper is confirmed, press Save all — it is at the top and at the bottom of the page.
Nothing is written until you press Save all. Before that you can change anything. If you accidentally check the same learner twice, QuickCheck warns you before replacing their score. Papers you have not reviewed stay in the queue, so a partial save never loses them.
13

See the results and download your reports

Everything about the exam, in one place.

Go to Results

  1. Pick the test you want. You'll see the class average and how the class spread out.
  2. Then choose what you want to look at:
    • Item analysis — which questions were hardest, and how each choice was picked.
    • Competencies — which competencies were not mastered, weakest first, and who needs help in each. (Needs a TOS — part 6.)
    • Scores (Excel) — the score sheet.
    • Formal report — a full test report you can read on screen or download as PDF or Excel: results summary (mean, SD, MPS and proficiency levels, by sex), learner proficiency list, score distribution and item analysis, least mastered competencies, the Table of Specifications and a learner-by-competency matrix. The interpretation and recommendations are written for you, and you can edit them.
    • Complete report — every part in one Excel file. This is the one to download when you're asked to submit documents.
    • Marked papers — the photos with the ticks, if you need to show a learner or a parent.
  3. Use the tabs at the top of any of those pages to move between them without going back.
That's the whole cycle: class → test → answer key → print → check → results. Next time you skip straight to making the test and checking.
14

Keep your work safe

Worth two minutes now, saves a bad day later.

  1. QuickCheck keeps everything in two folders next to the app: data (classes, tests, keys, results) and output (sheets, reports, backups).
  2. To back up, copy those two folders to a USB drive or a cloud folder.
  3. Or go to Settings → Backup & restore → Export everything (.zip) for one file with everything in it, including your Excel class records. Restore from .zip checks the backup first and saves your current work before it adds anything.
  4. Before every save into your class record, QuickCheck keeps a dated copy of that file — so a bad save can always be undone.
Saved photos take the most space. Once you no longer need to look at the papers, go to Results → Saved paper photos → delete them. All scores and answers are kept — you just can't view the marked photo afterwards.
Moving to another computer? Settings has a Moving to another computer section that tells you exactly what to copy — and remember the key is tied to one computer, so ask for a new one.
15

Updating QuickCheck

From version 2.2.0 onwards, updates install with one click.

  1. When a new version is out, a line appears at the top of the app: QuickCheck 2.3.0 is available — Update now. (You can also check any time in Settings → About QuickCheck.)
  2. Press Update now. It downloads in the background — keep working. QuickCheck checks the update is genuine and complete before it uses it.
  3. Press Restart QuickCheck. The window closes and opens again by itself a few seconds later, on the new version.
Nothing to download or delete by hand. Your classes, tests, scores and reports are never touched by an update, and the old copy is cleaned up for you. If your computer has no internet, just download the new zip on the website when you can — your data and output folders carry everything across.

If something goes wrong

The things teachers ask about most.

Windows says "Windows protected your PC"

Normal for a new app. Click More info → Run anyway.

The app opens, but my work disappears

You are running it from inside the zip. Close QuickCheck, extract the zip to a normal folder (part 1), and run the .exe from there.

My phone won't connect

Check three things: QuickCheck is open on the computer, both devices are on the same Wi-Fi, and you scanned today's QR code. School Wi-Fi sometimes blocks devices from talking to each other — if so, use your phone's hotspot and connect the computer to it.

A paper wouldn't read

Retake the photo with the whole sheet in frame, including all four black corner squares, in good light and roughly straight on. Avoid shadows across the page. If it still fails, check the sheet was printed at 100% and not shrunk.

"The class record is open in Excel"

Close the file in Excel and press save again. QuickCheck cannot write into a file while Excel has it open.

I can't edit the answer key any more

The key locks once papers have been uploaded or saved with it, so scores can't change behind your back. Remove those papers, fix the key, then check them again.

I need it on another computer

Your key works on one computer. Message us for a key for the new machine, and copy your data and output folders across.
