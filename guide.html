How to use QuickCheck

Everything, in the order you will actually do it. Follow it once from top to bottom. After that, checking a whole class takes a few minutes.

💡

You can't get lost. QuickCheck always shows the next button to press — the green one. If you are ever unsure what to do, look for the green button and press it.

1

Install QuickCheck on your computer

You only do this once. About two minutes.

  1. Download the .zip file from the link you were given.
  2. Google Drive may say "can't scan this file for viruses" — that is only because the file is large. Click Download anyway.
  3. Right-click the .zip → Extract All, and put the folder somewhere normal like Documents.
  4. Open the folder and double-click QuickCheck.exe (or QuickCheckPro.exe for Pro).
  5. Windows may show a blue box saying "Windows protected your PC". Click More info, then Run anyway.
Extract the zip first — this matters. If you run QuickCheck from inside the zip, Windows throws your work away when you close it. Extract to a real folder and everything is saved properly.
The blue warning is normal. Windows shows it for any new app that hasn't paid for a certificate. It is not a virus warning.
2

Your free trial, and entering your key

No key is needed for the first 7 days.

  1. The first time you open QuickCheck, a 7-day free trial starts by itself. A bar at the top shows how many days are left.
  2. When you buy, you receive a small file ending in .qckey. Click Buy or enter a key on that bar.
  3. Put the .qckey file in the same folder as QuickCheck, and a one-click Activate button appears. Otherwise click Choose a file and pick it.
  4. Press Activate. That's it — you won't be asked again, and everything you made during the trial stays.
When the trial ends. QuickCheck becomes view-only: you can still open and download your results, but you can't check new papers until you enter a key. The free trial is once per computer.
One key, one computer. Your key locks to the computer you activate it on. If you change computers, ask for a new key. A key with a time limit starts counting from the day you activate it, not the day it was made.
3

Add your class list

QuickCheck needs to know your learners' names so it can match each paper.

Go to Class Lists

Option A — use your DepEd class record (recommended)

  1. Click Upload class record and choose your .xlsx e-class record.
  2. QuickCheck reads the learner names from it.
  3. When you save scores later, they go straight into that same file, in the right column — so you don't retype anything.

Option B — just type the names

  1. Click New simple class.
  2. Type or paste the names, one per line, and save.
Which should you pick? Use your DepEd record if you have one — scores land in the file you already submit. A simple class is fine for quizzes, but its scores live inside QuickCheck, so download them if you need them elsewhere.
4

Create a test

One test = one exam or quiz.

Go to Check Papers → Create test

  1. Name it the way you'd say it out loud, e.g. "First Term Exam — Math 8".
  2. Pick the class it belongs to.
  3. Type how many items it has.
  4. Choose the answer type:
    • True/False, A–C, A–D, A–E — ordinary multiple choice.
    • Matching type — A–F up to A–N. Every question gets one bubble per option, so a 10-item matching set gives each row A to J.
  5. Choose the term and which column the score belongs in (e.g. Written Works 1).
  6. Press Create test.
Matching type: fewer options are easier for learners to shade accurately. If your matching set has more than about 10 answers, consider splitting it into two shorter sets.
5

Build a Table of Specifications (Pro only, optional)

Do this if you want to know which competencies your learners did not master.

Right after you create a test, Pro asks: build a TOS, or skip?

  1. Type each competency you taught, and how many days you spent on it.
  2. QuickCheck works out the rest the DepEd way — days ÷ total days × total items — and the item counts always add up exactly to your test.
  3. Each competency is given its own item numbers (for example, items 39–50).
  4. Press Save Table of Specifications. You go straight on to the answer key.
Why this is worth five minutes. Because each competency owns specific item numbers, after you check the papers QuickCheck can tell you which competencies the class failed and which learners need help in each one — with no extra typing. You can also print the TOS itself, which many schools ask for.
You can skip it. Skipping is completely fine — you still get scores and item analysis. You can also add a TOS later from the test's TOS button.
6

Type the answer key

The correct answers. Without this, nothing can be scored.

  1. You land on the answer key screen automatically.
  2. Click the correct letter for each item — 1, 2, 3, and so on.
  3. It saves as you go. The test shows Key ready when every item is filled.
Made a mistake? Open the test any time and press Edit answer key. If you already checked papers, fix the key and check them again — the corrected scores replace the old ones.
7

Print the answer sheets

Learners must use QuickCheck's sheet — that's what the camera reads.

Go to Print Sheets

  1. Pick your test. QuickCheck makes the sheet in the right format automatically.
  2. Choose blank sheets (learners write their own name) or named sheets (one per learner, name already printed).
  3. Download the PDF and print it on plain A4 paper.
Print at 100% — do not "fit to page". The four black corner marks are how the camera finds and straightens the sheet. If the page is shrunk, or the corners are cut off, the paper cannot be read. Photocopies are fine as long as they are clear and not skewed.
8

Give the test

Nothing to do in the app — just two things to tell your class.

  1. Shade the bubble fully, with a dark pen or pencil.
  2. One bubble per question. Two marks on the same question can't be counted.
  3. Write the name clearly if you printed blank sheets.
9

Check the papers

The part that used to take your evening.

Go to Check Papers → open your test → Take a photo

Option A — check from your phone (fastest)

  1. On the computer, open Phone Access.
  2. Point your phone camera at the QR code on the screen and tap the link that pops up. No typing.
  3. Type the PIN shown on that same page. You only do this once per phone.
  4. On the phone, open your test and press Take a photo.
  5. Snap each paper. Photos upload straight to the computer.
Two things must be true The phone and the computer must be on the same Wi-Fi, and QuickCheck must be open on the computer. No Wi-Fi? Turn on your phone's hotspot and connect the computer to it — that works anywhere and uses no mobile data. The address changes on every network, so just scan the QR code each time.

Option B — check from the computer

  1. Open the test and press Choose files instead.
  2. Pick your photos, a scanned PDF (each page = one paper), or a .zip.
  3. Press Upload & review.
A whole class takes a moment to read. That is normal — wait for the review page. Your progress is saved, so you can stop and come back later.
10

Review each paper, then save

You always see and approve every paper before anything is recorded.

  1. For each paper you see the photo with green and red marks and the answers it read.
  2. Check the name is the right learner. Change it from the list if not.
  3. If a bubble was misread, change that answer from the dropdown. The score updates.
  4. Press Confirm and move to the next paper.
  5. When you're done, press Save all — it's at the top and at the bottom of the page.
Nothing is written until you press Save all. Before that you can change anything. If you accidentally check the same learner twice, QuickCheck warns you before replacing their score.
11

See the results and download your reports

Everything about the exam, in one place.

Go to Results

  1. Pick the test you want. You'll see the class average and how the class spread out.
  2. Then choose what you want to look at:
    • Item analysis — which questions were hardest.
    • Competencies (Pro) — which competencies were not mastered, weakest first, and who needs help in each.
    • Scores (Excel) — the score sheet.
    • Formal report — a formal test report you can read on screen or download as PDF or Excel: results summary (mean, SD, MPS and proficiency levels, by sex), learner proficiency list, score distribution and item analysis. Pro adds least mastered competencies, the Table of Specifications and a learner-by-competency matrix. The interpretation and recommendations are written for you, and you can edit them.
    • Complete report — every part in one Excel file. This is the one to download when you're asked to submit documents.
    • Marked papers — the photos with the ticks, if you need to show a learner.
  3. Use the tabs at the top of any of those pages to move between them without going back.
That's the whole cycle: class list → test → answer key → print → check → results. Next time you skip straight to printing and checking.
12

Keep your work safe

Worth two minutes now, saves a bad day later.

  1. QuickCheck keeps everything in two folders next to the app: data (tests, keys, results) and output (sheets, reports, backups).
  2. To back up, copy those two folders to a USB drive or cloud folder.
  3. Or go to Settings → Download a backup for one zip of everything.
  4. Before every save into your class record, QuickCheck keeps a dated copy of that file — so a bad save can always be undone.
Saved photos take the most space. Once you no longer need to look at the papers, go to Results → Storage and saved paper photos → delete them. All scores and answers are kept — you just can't view the marked photo afterwards.

If something goes wrong

The five things teachers ask about most.

Windows says "Windows protected your PC"

Normal for a new app. Click More info → Run anyway.

My phone won't connect

Check three things: QuickCheck is open on the computer, both devices are on the same Wi-Fi, and you scanned today's QR code. School Wi-Fi sometimes blocks devices from talking to each other — if so, use your phone's hotspot and connect the computer to it.

A paper wouldn't read

Retake the photo with the whole sheet in frame, including all four black corner marks, in good light and roughly straight on. Avoid shadows across the page. If it still fails, check the sheet was printed at 100% and not shrunk.

"The class record is open in Excel"

Close the file in Excel and press save again. QuickCheck cannot write into a file while Excel has it open.

I need it on another computer

Your key works on one computer. Message us for a key for the new machine, and copy your data and output folders across.
